# Aryan Saini — Portfolio

A static, dark-mode portfolio with red accents, hosted at https://aryansx.github.io/.

Built with semantic HTML, responsive CSS, and a small vanilla JavaScript motion layer. No build step or dependencies.

Includes scroll reveals, a scroll-progress indicator, active section navigation, pointer-responsive project cards, and a geometric hero animation. Motion follows the visitor's reduced-motion preference and can be paused with the footer control. The content remains available without JavaScript.

The featured ChemSpec screenshot comes from the project's public README:
https://github.com/charles-mills/ChemSpec

Edit `index.html` for content, `styles.css` for presentation, and `motion.js` for animation behavior. GitHub Pages serves the `main` branch directly.
